# 立场判定口径 v3（2026-11-18 定版）

> 适用于 2ch / X 日语政治帖的三分类：`yes`（修宪派）/ `no`（护宪派）/ `other`（无立场）。
> 本版在 v2（政策层映射）基础上，新增**第 6 条：情绪性表态计入 yes** —— 依据是用户对 40 条复查样本的判定（37/40 一致，3 条 other→yes 全部属此类）。

---

## 一、核心定义

| 标签 | 定义 |
|---|---|
| **yes** | 支持、或至少不反对高市政府的「推进」议题；或反对政府「反对」的议题 |
| **no** | 反对任一「推进」议题；或支持政府「反对」的议题 |
| **other** | 作者没有可判定的立场（转述、纯骂无指向、无关杂谈、信息不足） |

## 二、议题 → 政府立场对照表

| 政府立场 | 议题 |
|---|---|
| **推进（支持 = yes）** | 自衛隊明記、9条改正、緊急事態条項、96条/国民投票法、台湾有事/存立危機事態、安保法制/集団的自衛権、敵基地攻撃能力/反撃能力、防衛費増額、武器輸出、**核武装/核共有/非核三原則見直し**（2026-11-19 用户确认：属政策议题，**支持 = yes、反对 = no**；判断依据只看作者自身是否主张/反对，若仅反问或转述他人主张则走第②③条）、スパイ防止法、原発再稼働、積極財政/消費減税、靖国、領土（尖閣/北方四島/竹島）、辺野古基地、拉致問題、教育/国旗損壊罪、選挙制度（合区解消） |
| **反对（支持 = no）** | 移民・外国人受け入れ拡大、夫婦別姓、同性婚 |
| **中立（不据此判方向）** | 皇室（男系維持 vs 典範改正混在）、コロナ対策 |

## 三、判定流程（按顺序走，命中即停）

```
① 作者自己有没有表态？         没有 → other
② 表的是哪个议题？             不在上表 → ③（看是否属第 6 条）
③ 是作者的话还是引别人的话？   引用/转述 → other
④ 该议题政府立场是什么？       支持推进 = yes；反对推进 = no；
                              支持政府反对的议题 = no
⑤ 站哪一侧？                   民族主义/反中/强化国防一侧 → yes
                              护宪/反战/反基地一侧 → no
⑥ 是否属「情绪性表态」？       是 → 按第 6 条判，不判 other   ★v3 新增
⑦ 是反讽吗？                   能明确读出作者真实立场 → 判那个立场
                              读不出作者在主张什么 → other   ★2026-11-19 用户确认
⑧ 属哪类语篇？                 见「九、语篇类型细则」H1–H5  ★2026-11-20 校准
```

> **第 ⑦ 条说明（用户 2026-11-19 拍板，选「方案 A：现状」）**：
> 反讽**不是一个独立的判定维度**，处理方式与其他句式相同——
> - 若从反讽中能**明确读出作者的真实立场**（如 `改憲反対してるパヨク` = 作者站改宪侧 → `yes`；`ネトウヨは普通の軍隊にしたいんでしょ` = 作者站护宪侧 → `no`），**就判那个立场**；
> - 若读完只知道"作者在嘲讽"，**读不出作者自己在主张什么**，判 `other`（承接第 ③ 条）。
> - 因此模型的 6 个「立场词 × 嘲讽壳」交叉特征保留，不作废。

## 四、第 6 条（v3 新增）：情绪性表态计入 yes

**规则**：凡明确站在「民族主义 / 反中 / 强化国防」一侧的情绪表达，**即使没有提到改宪、9 条、自卫队**，也判 `yes`。

### 判 yes 的示例（用户已确认）

| 原文 | 译文 | 之前误判 |
|---|---|---|
| チョーセンジンはヴァカだwww | 朝鲜人都是傻子www | other → **yes** |
| 天安門に巡航ミサイル着弾したのが見てみたい | 想看看巡航导弹落在天安门 | other → **yes** |
| ９条と関係ないだろ…９条あろうがなかろうが巻き込まれる | 那跟 9 条没关系吧…有没有 9 条都会被卷进去 | other → **yes** |

### 同理可判 yes 的类型

- 排外辱骂（对朝鲜/中国/库尔德移民等群体）
- 反中挑衅、期待中国出事
- 主张日本应更强硬、应拥核、应扩军
- 贬低护宪派/左翼/在野党的民族主义式嘲讽（有明确对象）

### 仍然判 other 的（不是情绪表态）

| 类型 | 例 |
|---|---|
| 无指向的骂人 | 「はよ潰してや」「気持ち悪いなぁ」 |
| 纯问候/季语/表情 | 「おはようございます☀」 |
| 乱码/图片链接/复读 | 「ふなふな」「グルル…!!」 |
| 转述新闻/引他人观点 | 「トランプが WHO 脱退方針」 |
| 无立场的政治闲谈 | 「立憲が議席増やしても何も変わらん」 |
| 提问、求助、信息询问 | 「憲法改正の手続きは？」 |

## 五、no 侧的口径（同样要宽）

**委婉表达也算 no**，不要因为没出现"反对"二字就判 other：

| 原文 | 译文 | 判 |
|---|---|---|
| 急ぐべきではない | 不该急着来 | **no** |
| 慎重に議論すべき | 应慎重讨论 | **no** |
| 9条は世界遺産 | 9 条是世界遗产 | **no** |
| 今の憲法で足りている | 现行宪法够用 | **no** |
| 戦争する国にしないで | 别把日本变成能打仗的国家 | **no** |

## 六、边界案例（已确认，直接照用）

| 情形 | 判 | 备注 |
|---|---|---|
| 批评"手法"而非内容（后出し、越权） | other | 未对政策表态 |
| 批评自民党"让护宪派当干事长" | yes（弱） | 隐含支持明记 |
| 讽刺立宪转向改宪（おめでとう） | other | 讽刺，无自身命题 |
| 报道公明党改宪姿势 | other | 转述 |
| 「郷に入れば郷に従え」反外国人 | yes | 反移民 |
| 「台湾はひとつの国、中国に物言えるのか」 | yes | 挺台 + 批政府软弱 |
| 「移民は簡単に消せる程度、恐れるな」 | no | 亲移民/反排外 |
| 担心紧急事态=威玛宪法 | no | 反政府议题 |

## 七、三条禁忌（避免系统性偏差）

1. **不要因为没提"改宪"就判 other** —— 第 6 条就是为了修这个偏差。
2. **不要因为语气粗俗就判 other** —— 粗俗但立场明确的，照判方向。
3. **不要因为提到议题词就判 other** —— 这是旧模型的病（B 层翻面率 49% 即此）。

## 九、语篇类型细则（H1–H5，2026-11-20 用户确认采纳）

> 来源：30 条分歧样本校准，覆盖 27/30，误伤 0。细节见 
eports/stageA_calibration_result.md。
> 用法：走完 ①–⑦ 后，若仍无法确定，用本节 H1–H5 定夺。

### H1 辱骂类

| 情形 | 判 |
|---|---|
| 泛称辱骂（土人/ゴミ/バカ），无明确对象、无政策连带 | **other** |
| 指向明确国家/族群/阵营（チョン/支那/朝鮮人/ネトウヨ/パヨク）且带敌意或政策连带 | **判其阵营方向** |

**锚点**：内政干渉すんなよ土人 → other；統一チョン猿はもういいです → yes；支那軍が世界警察？ → yes；ネトウヨって…在日ウンコ → no

### H2 转述类

| 情形 | 判 |
|---|---|
| 纯引述他人主张（「…」+と主張/と述べ），作者无自身表态 | **other** |
| 批驳对方且显露作者自身阵营 | **判该阵营** |

**锚点**：岡田は「憲法改正は絶対に反対！」と主張してる → other；福島香織氏の高市総理称賛発言「…」 → other

### H3 分析类

| 情形 | 判 |
|---|---|
| 纯局势预测 / 军力分析 / 历史论述，无价值判断 | **other** |
| 分析中含 应/不该/危险/必要 等价值判断 | **判该方向** |

**锚点**：アベが菅と…移民推進派に権力をあたえることで → other；中国は覇権国家を目指している。だから防衛戦争に勝てる備え → yes

### H4 骂阵营类

| 情形 | 判 |
|---|---|
| 骂在野党/左翼/右翼，但未连带任何政策主张 | **other** |
| 骂的同时连带支持或反对某项政策 | **判该方向** |

**锚点**：青木理氏の著書を「薄っぺらいサヨク小児病」と評した…ネトウヨはどうなんだ → other；スウェーデン移民政策の失敗 パヨクのせいで → yes

### H5 批程序/绩效类

| 情形 | 判 |
|---|---|
| 批程序（强行表决、越权）、批待遇、批经济绩效 | **other** |
| 直接反对政策内容本身（反对核武装/反对明记/反对法案） | **no** |

**锚点**：戦時下でしか改憲出来ないのか？平時にこそ民意を問うのが正道 → other；明らかに民主党時代のほうがマシだった アベノミクス… → other

### 三条例外（用户 2026-11-20 裁决：按原判保留）

| 原文 | 判 | 说明 |
|---|---|---|
| 少子高齢化で…日本国籍や永住権を与えるべきではないよ | **yes** | 有明确政策主张（反移民/限制国籍），不走 H5 |
| こいつは今まで改憲に向けた活動とかしてきたのか？LGBTとか… | **yes** | 嫌不够彻底，判 yes（弱） |
| 駆けつけ警護…経済的徴兵だよね | **no** | 批自卫队政策内容，判 no；与「経済的徴兵制…可能性」一致 |

> **H5 的边界**：批程序/待遇/绩效→other；批政策内容→no。経済的徴兵だよね 属后者（批政策内容），故判 no。
